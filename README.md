# 신사업 진단 AI (suniC)

> 🔒 **비공개 저장소입니다.** `data/표준역량_정의.csv`에 조직 구성원 실명과 사내 성과
> 지표가 포함되어 있습니다. 앱 구동에 필요한 파일이라 제외할 수 없으므로,
> **저장소를 Public으로 전환하거나 외부에 공유하지 마세요.**
> (한 번 Public이 되면 커밋 히스토리에 남아 되돌리기 어렵습니다.)

조직이 보유한 역량을 기반으로 진입 가능한 신사업을 도출하고, 부족한 역량과 보완 방향까지 제시하는 진단 도구입니다.

SKT 전략기획팀 멘토님이 현업에서 겪은 문제 — **역량 정보가 부서별로 흩어져 있고, 판단 기준이 주관적이라 근거 있는 의사결정이 어렵다** — 에서 출발했습니다.

---

## 두 가지 진단 모드

| 모드 | 질문 | 동작 |
|---|---|---|
| **역량 기반 추천형** | "우리 역량으로 뭘 할 수 있지?" | 신사업 DB 50건을 자동 채점해 Top-3 제시 + DB 밖 신규 후보 LLM 제안 |
| **아이디어 적합도 판단형** | "이 아이디어, 우리한테 맞나?" | 4개 항목 입력 → 요구역량 추출 → 100점 채점 |

두 모드 모두 **8개 평가 항목 100점** 기준이라 결과를 나란히 비교할 수 있습니다.

| 계열 | 항목 | 배점 |
|---|---|---:|
| 조직 55 | 조직역량적합도 / 역량전이가능성 / 부족역량수준 / 실행가능성 | 20 / 15 / 15 / 5 |
| 시장 45 | 시장성 / 경쟁강도 / 진입장벽 / 사업성 | 15 / 10 / 10 / 10 |

## 로컬 실행

```bash
pip install -r requirements.txt
cp .env.example .env        # OPENAI_API_KEY 입력
streamlit run main.py
```

조직 자료 3종(조직소개서 `.pptx`, 인력정보 `.xlsx`, 특허목록 `.xlsx`)을 업로드하면 시작합니다.

## 배포 (Render)

`render.yaml`이 포함되어 있어 Blueprint로 바로 배포할 수 있습니다.
`OPENAI_API_KEY`는 Render 대시보드 **Environment** 탭에서 입력하세요.

> **메모리 주의** — free/starter 플랜은 512MB입니다. 아이디어 적합도 판단형이 쓰는
> 임베딩 모델이 400MB 이상을 점유하므로, 그 기능까지 안정적으로 쓰려면
> standard(2GB) 이상을 권합니다. 역량 기반 추천형은 free에서도 동작합니다.

## 설계 원칙

**미확인은 0점이 아니다** — 평가할 수 없는 항목은 `None`으로 두고 분모에서 제외한 뒤 100점으로 환산합니다. 0점을 주면 "자료가 없다"가 "나쁘다"로 바뀝니다.

**역량 축을 하나로 통일** — DB 자유태그 177개와 조직 역량 11개를 **표준역량 32개**로 모아서 비교합니다.

**근거 없는 문장 금지** — LLM이 생성하는 모든 서술은 실재하는 근거 ID 인용을 강제하고, 응답 후 화이트리스트로 재검증합니다. 점수는 파이썬이 계산하고 LLM은 설명만 씁니다.

## 데이터 관련 안내

### 저장소에 포함하지 않는 것

`samples/`(조직소개서·인력정보·특허목록)와 `core/upload/organization_profile.json`은 조직 실데이터라 `.gitignore`로 제외합니다. 없어도 앱은 정상 실행되며, 사용자가 직접 파일을 업로드해 사용합니다.

> **저장소가 비공개여도 계속 제외해야 합니다.** Render 배포 URL은 링크만 알면
> 누구나 접속할 수 있어서, 이 파일들을 커밋하면 배포 서버에 올라가고
> `?dev=1` 개발 모드로 조직 데이터가 노출됩니다.

### 저장소에 포함되는 것 (주의)

`data/표준역량_정의.csv`는 `F3-2`가 조직계열 55점을 계산하는 데 필요해 제외할 수 없습니다. 다음이 들어 있습니다.

- `전담인력` 컬럼 — 구성원 실명 11명
- `근거` 컬럼 — 사내 성과 지표 (특허 건수, 상용화 실적 등)

**필요하다면 익명화할 수 있습니다.** 점수 계산은 전담인력이 *비어 있는지 여부*만 보므로, 이름을 `연구원 A` 형태로 바꿔도 결과가 달라지지 않습니다. 화면의 근거 문장 표현만 바뀝니다.
